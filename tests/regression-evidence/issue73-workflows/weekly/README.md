## Adopted job and limits

[ChatGPT design collaboration](https://chatgpt.com/g/g-p-6aa29ec1fa488191b154aa26f6464bcc-gh-projects-boards/c/6ab45fb6-9f50-83ee-9956-f93df2fc0e7f) adopted this bounded job: **correct progress/actual dates, understand the adopted calculation, and continue the same task**. The route connects Gantt's explanation to progress correction, visible date/field validation, confirmed versus pending effort, and the same table cell. Leaving an edited task-details candidate requires an explicit discard decision. The existing Project workspace and task-details dialog remain the working context.

Preserved contracts: Actual does not infer progress; Unstarted uses Estimate; InProgress/Reopened uses confirmed Remaining; reporting date and Project replanning cutoff are separate; Manual endpoints, historical attribution, operation Undo, and pending table input remain independent. No new scheduling rule, inferred time/assignment, dependency, wizard, live Apply, held Summary/workload/CSV feature, or performance campaign is part of this slice.
