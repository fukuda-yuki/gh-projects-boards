# Planning contract

The current day-level planning contract is maintained in the [specification](spec.md#current-planning-editor-scheduling-contract-78). It defines scheduling precedence, hierarchy, finish-to-start dependencies, calendars, typed edits, calculated dates, roll-ups, reasons and warnings.

The [plan sheet contract](spec.md#current-plan-sheet-and-row-aligned-gantt-78) defines native editing and presentation. The [local-document contract](spec.md#current-local-plan-document-operations-and-storage-78--79--81) defines operation-level Undo and durable storage. [Architecture](architecture.md) defines the Core/UI boundary; [requirements](requirements.md) and [decisions](decisions.md) define the product direction.
